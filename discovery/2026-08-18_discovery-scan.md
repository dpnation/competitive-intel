# Discovery Scan — 2026-08-18

## Summary
Two candidates found this week, both in accessibility testing-as-a-service: TestParty, an AI-plus-human accessibility remediation platform (NY-based, VC-backed), and White Test Lab, a managed QA firm whose core specialty is manual accessibility testing with real users with disabilities. Neither is currently in competitors.json or watchlist.json.

## Candidates Found

### TestParty
**Match type:** review-platform
**Why it matches:** Human-first digital accessibility compliance platform — AI detection paired with expert-delivered source code remediation (via GitHub pull requests), plus training and monitoring. Targets enterprise/ecommerce sites; positions directly against Level Access, Fable and AudioEye, all already tracked or watchlisted. $4M seed (2024), still actively publishing enterprise-accessibility comparison content in 2026.
**Source:** [testparty.ai](https://testparty.ai/)

### White Test Lab
**Match type:** review-platform
**Why it matches:** Managed testing services firm specializing in accessibility testing (WCAG 2.1 A/AA/AAA, EN 301 549 audits), combining manual testing with assistive technologies and real users with disabilities — the same "specialized testing as a service" model as Level Access/Fable/Digivante. Also offers UI/UX testing and general QA. Serves B2B tech, ecommerce, SaaS, finance, and healthcare — matches Applause's enterprise B2C buyer profile.
**Source:** [white-test.com](https://white-test.com/solutions/accessibility-testing/)

## Notes
Accessibility testing continues to be the most crowded sub-category surfacing in these scans (5th and 6th accessibility-focused name in as many weeks, after Level Access, Fable, AudioEye, and Digivante). Worth a standalone accessibility-competitor mini-map at some point rather than one-off watchlist adds.

AI evaluation/red-teaming and voice-AI QA searches this week (Cekura, QA.tech, LangWatch, oqoqo, Raindrop) surfaced only self-serve dev tools with no managed human-in-the-loop service layer — excluded per match criteria. Payment and localization testing searches surfaced no new qualifying entrants; results were dominated by incumbents (Testlio, Global App Testing) and non-testing payment infrastructure launches (FloPay, Paymentology).
